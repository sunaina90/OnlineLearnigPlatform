# Online Learning Platform

A full-stack web application for browsing, uploading, and downloading 
learning content, with user authentication and session management.

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Server:** Apache (XAMPP/LAMP)

## Features
- User registration and login with session management
- Home dashboard for browsing content
- Secure database connectivity via db.conn.php
- Responsive pages across devices

## Project Structure
- `index.php` — entry point
- `Home.html / home1.php` — main dashboard
- `Login.html / login.php` — authentication
- `logout.php` — session management
- `db.conn.php` — database connection layer
